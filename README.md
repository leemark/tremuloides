# Tremuloides

An offline-first camera web app (PWA) for Android that turns photos into art with **algorithmic lenses**: shaders and classic image processing, no generative AI. Named for *Populus tremuloides*, the quaking aspen.

**App:** https://leemark.github.io/tremuloides/. Open it in Chrome on Android, then choose **Install** (or ⋮ → Add to Home screen).

Built for field use. Once installed, it works with no connection at all. When you're back online, it downloads updates in the background and shows a **Reload** banner.

## Lenses
| Lens | What it does |
|---|---|
| Original | Plain photo, so you can re-edit it later with any lens |
| Ink & Wash (default) | Painterly strokes (anisotropic Kuwahara), palette stylization, ink edges |
| Posterize | Flat bands of lightness, colors kept |

More are planned in [PRD.md](PRD.md) §14: Quake, Field Log, Stained Glass, Flow Painter, Ridgeline Score, and Topo.

## Using it
- **Shutter** takes a full-resolution photo through the current lens.
- **Swipe** sideways on the viewfinder to change lens. **Press and hold** to see the unprocessed original.
- **Tap the lens name** to adjust its settings. Settings are remembered per lens.
- **Import** applies a lens to a photo that's already on your phone.
- In the **Gallery** you can share, save, re-edit (originals are kept), or delete.
- **Settings** shows the version, offline status, the update check, storage, and Diagnostics (with *Copy diagnostics* for bug reports).

## Development
```
npm ci
npm run dev             # http://localhost:5173/?demo=1 uses a procedural test scene instead of the camera
npm run typecheck
npm test
npm run build
npm run check:offline   # fails on external URLs or an incomplete precache
npm run check           # everything above
```

- **Deploy:** every push to `main` runs `.github/workflows/deploy.yml`. It runs the checks, builds with `BASE_PATH=/<repo>/`, and publishes to GitHub Pages. This needs repo Settings → Pages → Source = **GitHub Actions**.
- **Icons:** `public/icon.svg` and the PNGs are generated by `python3 scripts/make-icons.py` (needs Pillow) and committed.

See [AGENTS.md](AGENTS.md) for working rules, [PRD.md](PRD.md) for the full spec, and [docs/TESTING.md](docs/TESTING.md) for the on-phone test checklist.

## Layout
```
src/
  app/          screens (viewfinder, editor, gallery, detail, settings), UI helpers, capture pipeline
  camera/       camera stream, still capture + orientation fix, procedural test pattern
  gl/           WebGL2 helpers, renderer, shared shaders
  lenses/       one folder per lens (index.ts, shaders/, README.md) + registry.ts
  color/        Oklab/Oklch, k-means
  storage/      IndexedDB (captures, blobs, logs) with versioned migrations; settings
  pwa/          service worker registration and update flow
  diagnostics/  event log and the copyable report
tests/          Vitest unit tests
```
